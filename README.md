# TPS Quinto anno XML
Questo è un semplice repository basato su **XML**.

## Tecnologie:
- **JAVA**
- **XML**
- **CSS**

## Contenuti:
- **file XML**
- **XML Parser**

## Come scaricare i contenuti:

1. Clona il repository:

git clone https://github.com/MarioGiagnotti/TPS-quinto-anno-XML.git

2. Come testare i contenuti
 - 2.1 **Per i file contenuti in "file XML" basta semplicemente fare doppio click sul file**
 - 2.2 **Per i Parser**:
     - 2.2A -> Aprire la cartella DOMParser in Visual Studio Code e mandare in run il file JAVA
     - 2.2B -> Aprire la cartella DOMParser_byTag in Visual Studio Code e mandare in run il file JAVA
